# QA Desk UI Tests

Проект автоматизированных UI-тестов для сайта https://qa-desk.stand.praktikum-services.ru/

## Структура проекта

- `conftest.py` - фикстуры pytest
- `locators.py` - локаторы элементов страниц
- `tests/ - тестовые сценарии
- `data.py` - вспомогательные функции

## Установка и запуск

1. Установите зависимости:
pip install selenium pytest

2. Запуск теста в cmd
cd "путь к проекту"
pytest tests/ -v
